# GitHub Blog

Consultar `docs/PRD_SPEC.md`, `docs/TECH_SPEC.md` e `docs/TASKS_SPEC.md` antes de alterar a implementação. Trabalhar em tarefas incrementais; atualizar checklist e usar commits semânticos. Usar React, Vite, TypeScript estrito, Tailwind, Axios e React Router. Manter HTTP em serviços, modelos em types e lógica reutilizável em hooks. Não incluir segredos nem substituir o blog por dados simulados. Testar cenários observáveis, registrar o que realmente foi verificado e deixar a revisão e demonstração individual para o aluno.
